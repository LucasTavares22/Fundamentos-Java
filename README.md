# Exercícios e Estudos – Java Fundamentos (Curso Nelio Alves)

Este repositório contém meus estudos e exercícios práticos em Java, desenvolvidos durante o curso Java Básico ministrado por Nelio Alves.

O objetivo é consolidar os fundamentos da linguagem, a lógica de programação e as boas práticas de organização de código, formando uma base sólida para desenvolvimento back-end e, futuramente, para segurança de aplicações (cibersegurança).

## Conteúdos abordados

- Estrutura básica de um programa em Java
- Tipos de dados e variáveis
- Estruturas condicionais
- Estruturas de repetição
- Vetores e listas
- Métodos
- Introdução à Programação Orientada a Objetos (POO)

## Organização do repositório

Os exercícios estão organizados em pastas por temas, seguindo a ordem do curso.  
Exemplos:
- `1-estrutura-condicional`
- `2-estruturas-repetitivas`
- `3-vetores-listas`
- `4-intro-poo`

## Como executar os códigos

Os exercícios foram desenvolvidos utilizando Java 17 e podem ser executados em qualquer IDE (como IntelliJ ou Eclipse) ou via terminal com os comandos `javac` e `java`.

## Status do Projeto

Em desenvolvimento contínuo, com atualizações conforme avanço nos estudos.
